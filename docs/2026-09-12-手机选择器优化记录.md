## 最终交互

| 项目 | 实施方式 |
| --- | --- |
| 响应式 | 700px 及以下使用手机面板，其余宽度保留 Element Plus 下拉/级联菜单 |
| 打开 | 触发器为按钮，不是输入框；底部白色选择面板默认约占 82% 屏幕，最高 760px；不自动聚焦搜索输入 |
| 搜索 | 点击搜索框才进入输入；按名称查找，提供清空与无结果提示；中文候选词确认期间的 Enter 不主动关闭输入 |
| 单选 | 当前项浅蓝背景加勾选，整行可点；选中即应用并关闭，关闭按钮/遮罩/Escape 不修改原选择 |
| 多选 | 神契筛选使用临时数组，点“完成”才应用；清空同样先修改临时选择，关闭丢弃本次未完成选择 |
| 士兵 | 保留兵种分类与数据顺序；左侧分类，右侧完整名称和图片；搜索跨兵种并标注分类；回写原有 `[兵种, 士兵名]` 路径 |
| 图片和名称 | 手机图片 40×40px，PC 选项图片 32×32px，均使用 `object-fit: contain`；名称可以自然换行，图片不占用其余文字宽度 |
| 高度与滚动 | 搜索栏固定在面板顶部，列表内部滚动；使用 Visual Viewport 的高度和偏移适配可用区域，保留底部安全区，背景页面由抽屉组件锁定滚动 |
| 返回与定位 | 关闭后焦点回到原按钮，使用 `preventScroll`；重开定位当前选项和分类；选择期间隐藏页面底部快捷操作 |
| 键盘辅助 | 保留关闭和搜索的可访问名称；选项支持方向键/Home/End 浏览；PC 继续使用原下拉控件的键盘行为 |

这里新增的是选择控件内部搜索体验，没有推进此前暂缓的通篇查找/表格增强、缓存管理重做或加载性能专项。
